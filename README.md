# FURVERO Shopify Theme

Premium one-product Shopify Online Store 2.0 theme for Furvero.

## Requirements
- Shopify Online Store 2.0
- A real Furvero product created in Shopify
- Product variants/pricing configured in Shopify
- Optional Meta Pixel and GA4 IDs in Theme Settings

## Install
1. Upload this repository to GitHub.
2. In Shopify Admin go to Online Store > Themes.
3. Add theme > Connect from GitHub, or upload the ZIP.
4. Select the theme and Customize.
5. Select the Furvero product in the product section.
6. Configure images, colors, text and tracking IDs.
7. Test Add to Cart, cart drawer and Checkout before advertising.

No API keys or private credentials belong in this repository.
